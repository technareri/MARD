# Figures

This directory contains all figures from the MARD project:
**Predictive Modeling of Antibody Thermostability: Evaluation and Ranking of Machine Learning Models for Prediction Performance Based on Amino Acid Sequences**

## Adding Figures

Place figure files (`.png`, `.jpg`, `.svg`, or `.pdf`) in this directory. After adding or updating figures, update [`docs/index.html`](../docs/index.html) to include the new figure entry so it appears in the public gallery with a QR code.

## Accessing Figures

All figures are publicly accessible via their raw GitHub URL:

```
https://raw.githubusercontent.com/technareri/MARD/main/figures/<filename>
```

A browsable gallery with QR codes for every figure is available at the GitHub Pages site:

**https://technareri.github.io/MARD/**
